# Calculadora de Notas

Este projeto foi desenvolvido para calcular a média escolar com base em três notas, considerando os pesos definidos pela escola. A aplicação permite inserir as notas, calcular a média final e informar se o aluno foi aprovado ou reprovado.

## Objetivo

Calcular a média final do semestre com a fórmula:

(média) = (nota1 × 3 + nota2 × 3 + nota3 × 4) / 10

A média mínima para aprovação é 6.0.

## Estrutura do projeto

- [index.html](../index.html): página principal da calculadora
- [Assets/css/style.css](../Assets/css/style.css): estilos e layout da interface
- [Assets/js/script.js](../Assets/js/script.js): lógica de cálculo e validação das notas
- [docs/readme.md](readme.md): documentação do projeto

## Como usar

1. Abra o arquivo [index.html](../index.html) no navegador.
2. Informe as três notas nos campos disponíveis.
3. Clique no botão “Calcular Média”.
4. Veja o resultado final e o status de aprovação ou reprovação.

## Funcionalidades

- Entrada de notas de 0 a 10
- Validação dos valores informados
- Cálculo automático da média
- Exibição do resultado final em formato visual
- Mensagem de aprovação ou reprovação
